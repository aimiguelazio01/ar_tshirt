[01] IDLE LOOP (Frames 1 – 24)
  - Clip Name: 'idle_1_24' (AR) / 'sim_idle_1_24' (Simulator)

  - Loop Setting: THREE.LoopRepeat
  - Description: The default ambient resting loop. Character breathes gently,
    sways subtly, and holds hands ready. Plays continuously whenever no gesture
    or tap sequence is active.

[02] REACTION / DON'T TOUCH (Frames 25 – 72)
  - Clip Name: 'react_25_72' (AR) / 'sim_react_25_72' (Simulator)
  - Duration: 47 frames (~1.96s @ 24 FPS)
  - Loop Setting: THREE.LoopRepeat (2 cycles standard, 5 cycles on panic button)
  - Trigger: Directly tapping the 3D monster on screen or clicking the "DON'T TOUCH" button.
  - Audio: Accompanied by panic scream sound effect / panic music.
  - Return: Smoothly fades back to 'idle_1_24' when the sequence finishes.

  - Clip Name: 'loop_42_60' (AR) / 'sim_loop_42_60' (Simulator)

[05] LEFT ARM UP (Frames 73 – 80)

3. GESTURE & INTERACTION BEHAVIOR SUMMARY
--------------------------------------------------------------------------------
- Left Arm Raised: Plays 73 -> 80, Clamps at 80, Hides Software Plates.
- Left Arm Lowered: Plays 81 -> 116, Triggers 3D Storm VFX, Restores Idle (1-24),
  Restores Software Plates.
- Right Arm Raised: Plays 117 -> 125, Clamps at 125, Hides Software Plates.
- Right Arm Lowered: Plays 126 -> 160, Triggers 3D Blast VFX, Restores Idle (1-24),
  Restores Software Plates.
- Monster Character Tapped: Plays 25 -> 72, Screams/Jumps, Restores Idle (1-24).
- Both Arms Lowered: Software Plates visible & touch-interactive.


--------------------------------------------------------------------------------
4. DEBUGGING HUD SHORTCUTS & APIS
--------------------------------------------------------------------------------
- On-Screen Debug HUD:
  - Element: #anim-frame-debug (located at top-center under gesture chip)
  - Displays real-time exact animation frame number (1 - 160), active clip name,
    and progress bar in large cyan typography.
  - Clicking the HUD toggles between Large (56px) and Extra-Large (88px) modes.

- Browser Console Inspection API:
  - window.getCurrentAnimationFrame()
    Returns an object with:
    {
      frame: <number>,       // e.g. 82
      clipName: <string>,    // e.g. "LEFT ARM DOWN (STORM)"
      rangeText: <string>,   // e.g. "[81–116]"
      progress: <number>,    // 0.0 to 1.0 within clip
      rawTime: <number>      // seconds elapsed in action
    }

- Interactive Test Functions in Console:
  - window.testLeftArmGesture(true)   // Simulate raising left arm
  - window.testLeftArmGesture(false)  // Simulate lowering left arm
  - window.testRightArmGesture(true)  // Simulate raising right arm
  - window.testRightArmGesture(false) // Simulate lowering right arm
